# План фич: главная, авторизация, рейтинг/отзывы, Seen
Создан: 2026-08-02

## Важное отличие от `optimization-plan.md`
Этот план сделан по структуре `02-create-plan.txt` (индекс + файл на задачу), но
содержание — 5 продуктовых фич из запроса пользователя, а не баги, найденные
статическим анализом. Промпты `03-09` в `.cursor/scripts/prompts/` написаны под
Go-пайплайн (`go build`, `main.go`, `internal/handler/...`) и не применимы
дословно к Django-проекту. Поле "Промпт" в каждой задаче ниже — это ТОЛЬКО
метка категории (взята из фиксированного списка, как того требует
`02-create-plan.txt`), реальное выполнение задач идёт напрямую в Agent Mode
(этим чатом или через `run-next-task.txt`, при этом шаг "прочитай и следуй
инструкциям промпта" нужно трактовать содержательно, а не дословно — там, где
промпт говорит "go build ./...", для этого проекта имеется в виду
`python manage.py check` / `pytest`).

## Ключевые решения (зафиксированы с пользователем)
- Авторизация: Login + регистрация нового пользователя (без сброса пароля).
- Watch today: случайный фильм из НЕпросмотренных заметок пользователя (Watch
  later), клик сразу открывает страницу фильма.
- Рейтинг: 10 отдельных кликабельных звёзд, целое число 1-10.
- Оценку/отзыв можно менять в любой момент; фильм можно вернуть из Seen в
  Watch later (данные оценки/отзыва при этом не стираются).
- Seen: сетка карточек с сортировкой (по оценке/дате) и фильтром по жанру.
- Допущение (не переспрашивал повторно, скажи если не так): "Watch later" на
  главной = только непросмотренные заметки; как только фильм отмечен Seen —
  он пропадает из главной и появляется в разделе Seen.
